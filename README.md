# Prestige Remote

Phone remote for **Prestige**, a custom dashboard app for a Samsung Tizen TV.

Open the pairing QR code on the TV (Prestige › Phone remote) and scan it. This page then lets you send video/stream links to the TV and control playback.

Commands travel through the public relay [ntfy.sh](https://ntfy.sh), addressed by the secret pairing code in the link's `#fragment`. The fragment is never sent to any server. This page contains no secrets.
